# Unseen Tech Registry

Public, version-controlled catalog of tool **recipes** and **video episodes** used by the
Unseen Tech Launcher Android app and website. No server — clients read these files through the
jsDelivr CDN:

```
https://cdn.jsdelivr.net/gh/LovelyLachu/unseentech-registry@main/<path>
```

## Layout

| Path | What | Edit? |
|---|---|---|
| `recipes/<owner>__<repo>.json` | One recipe per tool (lower-case id = file name) | ✅ via PR |
| `videos.json` | Master episode list, newest first | ✅ maintainers |
| `pages/page-N.json` | 10 episodes per page | ❌ generated by CI |
| `schemas/*.schema.json` | JSON Schemas (recipe v1, video, page) | ❌ synced automatically |
| `tools/registry-cli.mjs` | Validator / paginator | ❌ synced automatically |

## Add a recipe

1. Create `recipes/<owner>__<repo>.json` following `schemas/recipe.schema.json`
   (copy an existing recipe as a starting point).
2. Validate locally (Node 26+):
   ```bash
   node tools/registry-cli.mjs validate recipes
   ```
3. Open a pull request. CI validates every recipe.

Fields `verified` and `play_compatible` are set **only by maintainers** after review.
Not sure how to write one? Open a **Recipe request** issue with the GitHub URL.

## Security

Recipes run code on people's phones. Maintainers review every command. Report a suspicious
recipe by opening an issue (keep details minimal); it will be removed first and investigated after.
